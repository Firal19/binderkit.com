# Round eight — intake, a floating way to write, and a real cookie choice

## The conflict this started with

Both privacy pages said, live, **"no cookie on this page"** and **"This page sets no
cookie"**. Firaol chose real cookies with a banner, so those lines became false and were
rewritten rather than left standing. A cookie inventory now lives at `/privacy#cookies`,
which is what the banner links to.

The draft itself is **not** in a cookie: a cookie is capped at 4KB and is sent to the
server on every single request, and a half-written message about a house has no business
riding along with every image fetch. The choice lives in a cookie (`pho-consent`); the
draft lives in localStorage, gated on that choice. The privacy page says exactly this.

## Built

| | |
|---|---|
| **Phone, optional** | Both forms, `type=tel`, `autocomplete=tel`. Carried through `api/contact.js`, `api/waitlist.js`, the Convex schema (`v.optional`) and all five letters — HTML and plain text — but only rendered when someone gave one, so an empty row never becomes noise. |
| **Two ways to send** | Side by side, not an interstitial: a dialog would cost every sender a click to explain something most do not need. Neither is called faster, because both land in the same inbox. What is true is on the page — your own mail app leaves you a copy in Sent and takes attachments. |
| **Floating write-to-us** | An `<a href="mailto:">` in `build.mjs`'s tail, so it is on every page of every site, works with scripting off, and can be middle-clicked. Revealed past the first screen so it never competes with the hero's own CTA. |
| **Email spell-check** | On blur, Levenshtein against thirteen common domains, offering the spelling you probably meant. Never blocks. A mistyped address is the commonest reason a reply never arrives and the sender never finds out. |
| **Cookie choice** | Bottom-left card, two answers. "No" is honoured by storing nothing but the refusal. |
| **Draft that survives** | Debounced, 14-day expiry, a "put it back / start fresh" offer on return, and **cleared the moment the message sends**. |
